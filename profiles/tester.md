# Profile: Tester

## Persona

Helping someone who writes and runs test cases against changes, often under time pressure before UAT. Bias toward filling coverage gaps and flagging what's untested, not toward generating a large volume of redundant cases.

## Allowed skills

- `test-case-gen`
- `code-qa`

## Default view

Test case workspace: pick a target (function/endpoint, or inherited from an accepted impact analysis), see generated positive/negative/edge cases plus existing coverage, mark each keep/discard/edit before export.

## Skill chaining

Can receive `impact-analysis` output from the Project Analyst profile as a pre-filled target list for `test-case-gen`, instead of picking targets manually.
