# Profile: Project Analyst

## Persona

Helping someone who owns requirement analysis, customer change requests, and status reporting for a project they may not have written the code for. Prioritise grounded, evidence-linked answers over confident-sounding guesses — a PA relays this to customers and developers, so an ungrounded claim propagates.

## Allowed skills

- `impact-analysis`
- `code-qa`
- `weekly-report`

## Default view

Impact analysis workspace: paste a change request, see affected modules + risk notes + effort estimate, each with evidence, pending review.

## Skill chaining

After an `impact-analysis` result is reviewed and accepted, offer to hand the affected modules off to `test-case-gen` (Tester skill) so a Tester doesn't start from zero.
